# Cómo arrancar

1. Entra a AWS Academy, abre el Learner Lab y pulsa **Start Lab**.
   Deja abierta la pestaña **AWS Details**: el agente te pedirá las credenciales.
2. Abre Claude Code (pestaña Code de la app de escritorio) en esta carpeta `rag-fds`.
3. Pega este mensaje:

> Lee CLAUDE.md y la guía en docs/guia/RAG_FDS.pdf. Empieza la Fase 0 y detente en el checkpoint.

Al comenzar cada sesión nueva, pega:

> Lee CLAUDE.md, revisa en qué fase vamos y sigue desde ahí. Verifica primero las credenciales de AWS.

Qué hay en la carpeta:

- `CLAUDE.md`: instrucciones completas por fases para el agente.
- `docs/guia/RAG_FDS.pdf`: la guía del parcial.
- `data/raw/FDS EVALUADAS/`: las 101 fichas, por año.
- `.gitignore`: deja fuera credenciales y, por defecto, los PDFs originales.
